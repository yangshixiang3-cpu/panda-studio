# 参考图标注与清理

## 标注材质

1. 打开参考库，点「添加并标注…」选一张或多张图片，也可以把图片拖到分组外。多张图片会按顺序打开。拖到特定材质分组会继续按普通参考图加入该分组。
2. 选材质，在图上拖出矩形。点框选中后，可以拖动、拉四角或在下拉菜单中改材质。用 Delete 或框上的 × 删框。新画下一种材质前，点「画框」取消当前框选中，再选另一种材质。
3. 用滚轮放大或缩小。「平移」可拖动画面，点缩放百分比恢复全图。点「新材质…」添加分组，关键词默认是材质名称。分组标题旁的「关键词」支持用中英文逗号分隔多个词。
4. 点「保存」写入参考库。允许保存空标注图。点分组里的「标注」裁图会打开原图并选中这个框，也可以从「标注参考图」打开整张图。删除标注图需要再次确认，引用的源图片保留。

库记录位于 `refs/library.json` 的 `annotated` 列表。工作台保存长边至多 2400 像素的 JPEG 副本，并在 `refs/annotated/crops/` 保存各框的裁图。框坐标按原图宽高归一化。参考库优先提供标注裁图，再用已认可图或候选图。参考库每种材质最多提供 2 张图。

## 为本任务添加材质参考

在「AI 校准」的「材质参考」里点「添加并标注…」，或把图片拖入弹层。可多选 JPG、PNG、WebP，单张最多 50 MB。点缩略图可重新编辑，点右上角的 × 再确认可删除。

材质下拉会显示最近一轮小样中的场景材质和参考库材质。新材质可用于本任务内的其他参考图。勾选「也加入参考库」并保存会复制整图，其中只有参考库材质的框会带入库。取消勾选或删除任务参考会保留库内副本。可在参考库页编辑或删除这份副本。

AI 会优先对照本任务参考，每种材质最多取 2 张任务裁图。场景材质按原名精确匹配，参考库材质按分组关键词匹配，新材质按名称包含关系匹配。未匹配的新材质按用户给的名称列作「其他参考」，无框图列作「整体参考」。每张选中的裁图附平均 D65 Lab，两种引擎每轮合计最多收到 12 张图。

任务副本存放在 `exchange/tasks/<id>/calibration_refs/`，JPEG 长边至多 2400 像素，裁图在 `crops/`。每轮开始时固定本轮的参考版本，运行中修改会从下一轮生效。轮次记录保留实际提交的参考 ID 和从 0 开始的框序号，整图的框序号为 `null`。轮次卡片按来源图片计数。

## 清理交换目录

首页「已有任务」右侧显示交换目录大小。有可清理任务时，点「清理已入库任务」查看预计任务数和大小。手动清理适用于任何入库日期。自动清理在服务启动时及此后每 24 小时运行，默认清理入库超过 30 天的任务，保留天数可通过已有配置中的 `cleanup_delivered_after_days` 设置。

只有已经入库且没有排队、渲染或进行中 AI 校准的任务可以清理。上次入库后重新渲染的成品会保留到再次入库。清理包括任务目录里的 `smallshots/`、`calibration/`、`calibration_refs/`、`final/`、`references/` 和 `lighting/`。保留 `task.json`、`preview/`、参考库副本、产品 `sku/` 中的成品和产品「光向参考」中的文件。已清理任务仍可打开，已删除的缩略图和校准记录显示「已清理」。

- `GET /api/storage` 返回交换目录字节数、任务数和可清理任务数及字节数。
- `POST /api/storage/cleanup` 接收 `{"mode":"delivered"}`，返回本次清理的任务数和字节数。

## 隔离验收

```powershell
python -B codex-tasks/wb-10b-tmp/environment.py setup
node whitebg-studio/tests/refs_cleanup_flow.cjs
node whitebg-studio/tests/calibration_refs_flow.cjs
node whitebg-studio/tests/calibration_refs_flow.cjs --screens
```

浏览器使用 8796 端口，清理只针对 `tests/tmp/` 下的隔离任务。校准参考流程使用预备小样提供场景材质，并用假 Codex 验证第 0 轮和再调一轮。带 `--screens` 时以已完成第 0 轮的任务复跑并保存两张 1600 × 1000 截图。
