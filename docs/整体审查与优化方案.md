# Panda Studio 整体审查与优化方案（2026-11-22，基于 1.6.2）

审查方式：在隔离环境（`tests/tmp/review-stage`，假执行器 + 模拟生图接口，不碰真实数据）里按真实使用顺序走了一遍——首页扫描产品、新建任务、调画面和打光、出小样、渲染、入库、AI 校准、参考库、本机设置、AI 设置、画布——每一步截图，同时读了相关代码。

## 一、整体评价

软件的主线很清楚：**产品文件夹 → 白底任务（Max 出图）→ 入库**，另有**画布**做 AI 生图。白底流程的步骤条（出小样 → 渲染 → 入库）、入库前核对文件、旧文件自动归档，这些设计都合理，用起来不会出错。画布这几轮迭代下来功能已经够用。

问题主要不在「缺功能」，而在三类地方：**提示说得不准、界面细节冲突、画布用久了会卡、少了画布工具该有的基本操作（撤销、复制）**。所以这次的方案以「把已有的做顺」为主，不加大功能，也不引入新的第三方库：需要的功能（缩略图、撤销、剪贴板）用现有的 Pillow 和浏览器自带能力就能做，从 GitHub 拉库反而会让软件变臃肿。

## 二、发现的问题

### 交互和逻辑
1. **首页「先完成本机设置」提示说错原因**：判断的是「Max 程序」和「白底模板文件」两样，但提示永远写「指定 3ds Max 后才能出图」。真正缺模板时，用户去设置页一看 Max 明明是好的，会很困惑；右上角 Max 状态同时显示「已连接」，三处说法互相矛盾。
2. **参考库页右上角「添加并标注…」被窗口按钮压住**：无边框窗口的最小化 / 最大化 / 关闭按钮固定在右上角，这一页的标题栏没给它们让位。
3. **画布没有撤销**：移动、删除、连线、打组做错了只能手动改回去（只有删除后的提示条能撤销一次）。画布类工具里 Ctrl+Z 是基本预期。
4. **画布不能复制节点、不能复制图片**：想用同一套提示词和设置再开一个节点，只能新建后重新填；生成的图要发给别人，只能去文件夹里找。
5. **画布的快捷键藏得太深**：Delete、Ctrl+G、Ctrl+A、Shift 加选、Alt 拖动不对齐、中键平移、@ 引用，界面上看不到在哪说明。
6. **生成失败后要绕一圈才能重试**：节点上只有一个「失败」小标，要点开节点、读面板里的错误、再点生成。
7. **每次打开软件都回到首页**：最近主要在用画布，每次都要再点一次。

### 性能和可靠性
8. **画布用久了会卡**：节点、参考图栏、@ 列表、项目卡片、「画布参考」弹层，全都直接加载原图（2K～4K 的 PNG，一张几 MB）。几十个节点时内存和缩放、拖动都会变慢。
9. **关软件时可能丢最后一下改动**：画布改动后 0.5 秒才保存，这期间直接关窗口，最后一次改动会丢。
10. **生图记录只增不减**：`canvas/runs` 里每次生成一个记录文件，永远不清理。

### 文档
11. README 开头还写着 v1.3，画布、渠道等新内容散在后面，和现在的软件对不上。

## 三、10 轮优化（做进 1.7.0）

| 轮 | 内容 | 解决 |
|---|---|---|
| 1 | 首页提示按真正缺的东西说（缺 Max / 缺白底模板 / 都缺），按钮直接带到要改的地方；用内网渲染机时不提示 | 问题 1 |
| 2 | 所有页面的标题栏给右上角窗口按钮让位（参考库、设置等） | 问题 2 |
| 3 | 画布缩略图：服务端按需生成并缓存缩略图（Pillow），节点和各种小图都用缩略图，看大图、复制、拿去生图仍用原图 | 问题 8 |
| 4 | 画布撤销 / 重做：Ctrl+Z、Ctrl+Shift+Z（或 Ctrl+Y），覆盖移动、删除、连线、打组、新建、分出节点 | 问题 3 |
| 5 | 复制节点：Ctrl+C / Ctrl+V 复制粘贴选中的节点（带提示词和设置，偏移一点放），Ctrl+D 原地复制一份 | 问题 4 |
| 6 | 复制图片：节点工具条加「复制图片」，直接粘贴到微信、PS 等；看大图时也能复制 | 问题 4 |
| 7 | 快捷键说明：画布工具栏加「?」，列出所有鼠标和键盘操作 | 问题 5 |
| 8 | 失败直接重试：失败的节点中间显示简短原因和「重试」按钮 | 问题 6 |
| 9 | 关窗口不丢改动：页面关闭前立刻把没保存的画布存掉；打开软件时回到上次用的页面（首页 / 画布 / 参考库 / 设置） | 问题 7、9 |
| 10 | 清理和文档：生图记录只留最近 30 天（还在生成的不动）；README 改成现在的版本和结构 | 问题 10、11 |

每一轮都配自动测试或浏览器实测；全部做完后把所有测试跑一遍，再打 1.7.0 安装包，放在桌面上，1.6.2 的安装包保留不动。

## 四、这次不做的（以后可以考虑）
- 任务页的大画面直接切换看小样、成品（现在点左侧缩略图可以放大看，够用）。
- 首页任务搜索（现在任务不多）。
- 拆分 `app.js`、`canvas.js` 这两个 1000 多行的大文件：要动的地方太多，收益是以后改起来顺手，不影响使用，等哪次大改时再做。
