    生图渠道

    一个渠道 = 接口地址 + API Key + 模型。可以存好几个、随便改名，在输入面板里点模型切换。

    接口类型

    自动：模型名里带 gemini、banana 这类的走对话接口，其余走图片接口（/images）。Gemini 原生：走 /v1beta 的 generateContent（有的中转站的 Gemini 生图只能走这个）。生成失败时可以换一种。「拉取模型」只读模型列表，不花钱。同一个站点想用别的模型，点「复制为新渠道」再换模型。
